## Projetos em destaque

### Jardim Pet

*Aplicação full-stack · Em desenvolvimento*

E-commerce fictício que reúne pet shop e loja de plantas. Foi meu primeiro projeto completo de desenvolvimento web, inicialmente construído em HTML, CSS e JavaScript e, posteriormente, reestruturado em React, com back-end em Node.js e Express e banco de dados MySQL.

É o projeto em que mais venho trabalhando a integração entre front-end, back-end e banco de dados, sem deixar de lado a construção de uma identidade visual própria.

**Funcionalidades:**

- Catálogo de produtos;
- Carrinho de compras;
- Cadastro e autenticação de usuários;
- Gerenciamento de pedidos;
- Interface responsiva.

**Tecnologias:** React · JavaScript · CSS3 · Node.js · Express · MySQL · Axios · JWT · APIs REST

[Ver repositório](https://github.com/eduardasouzar-dev/jardim-pet-react) · [Demonstração da versão estática](https://eduardasouzar-dev.github.io/jardim-pet/)

### Catálogo de Filmes

Aplicação web para cadastro e consulta de filmes, com busca por título e filtro por gênero. Ao cadastrar um filme, o sistema consulta a API do TMDB para obter automaticamente suas informações e seu pôster.

Nesse projeto, trabalhei com o consumo de uma API externa, a comunicação entre cliente e servidor e o armazenamento dos dados em MySQL.

**Tecnologias:** HTML5 · CSS3 · JavaScript · Node.js · Express · MySQL · API TMDB

[Ver repositório](https://github.com/eduardasouzar-dev/catalogo-filmes)
